# Portafolio de Luis Valenzuela

Portafolio personal desarrollado con React, Vite, Ant Design y Tailwind CSS.

## Desarrollo local

```bash
npm install
npm run dev
```

## Verificación

```bash
npm run lint
npm run build
```

## Publicación

El flujo de GitHub Actions construye `dist` y lo publica en GitHub Pages después de cada cambio enviado a `main`. En **Settings → Pages**, la fuente debe estar configurada como **GitHub Actions**.
